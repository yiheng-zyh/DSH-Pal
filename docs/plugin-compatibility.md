# 手机端插件兼容与验证边界

适配优先级：**官方输入与文件/语音能力 → 官方工作台结构 → 可选插件区域 → 未知插件的保守回退**。App 不按本机插件清单决定界面，也不要求安装上下文、轨迹或右栏插件。

| 功能 | 手机端负责 | DSH / 插件仍负责 |
|---|---|---|
| 文件选择 | 系统选择器、多选与取消，只交付用户选择的 content URI | 文件处理、上传结果与附件插入 |
| 文件上传 | 保留官方请求体、取消与返回值，记录阶段及 HTTP 状态 | 官方上传 hook / Worker 与后端协议 |
| 下载 / 导出 | Blob 与同源 HTTP 保存、系统选择保存位置 | 导出内容、下载权限与生成结果 |
| 语音输入 / 转录 | 麦克风授权、采集与录音阶段、错误类型，不读取音频块 | 转写服务配置、模型、额度和文本回填 |
| 输入框、模型与权限菜单 | 手机尺寸与越界处理，保留菜单事件 | 当前会话状态和指令实际执行 |
| 对话 / 轨迹 / 上下文 | 对存在的标签页按语义绑定动画 | 哪些页面可用、加载与渲染 |

麦克风采集成功不代表转写服务已配置。未安装可选官方插件时，不伪造按钮或执行成功。官方上传 hook 不存在也不一概等同于故障，可能是该版本使用其他传输方式。

## 兼容规则

1. 中间区可以独立工作；左右栏采用工作台直接子元素识别，避免把插件内部同名元素当成全局侧栏。
2. 已知右栏状态协议下，整块不透明页面移动；仅最外层面板和 DockKit 宿主接受对应规则，不把嵌套插件的所有 `_panel` 改成全屏。
3. 未知右栏状态保留流式布局，不强行覆盖、隐藏或拦截其开关。
4. 头部仅对已识别的官方结构调整；缺少标签页、左栏或工具区时不硬留三行空位。
5. 标签页使用 `role=tablist` / `role=tab` / `aria-controls`，不靠“上下文”等文字判断；原点击事件交给 DSH。每组独立管理动画，连续切换取消上一段；已有 CSS 或 Web Animations 动画时不叠加。
6. 只有越界顶层菜单调整位置，嵌套菜单保留原逻辑。弹窗单独限制大小，只将横向溢出的直接 flex 行折成纵向。
7. 插件延迟挂载、移除、工作台重建时重新识别并清理旧标记、遮罩和动画；流式输出仅检查新增节点，不反复遍历历史消息。
8. 遵循减少动画偏好，以透明度和位移为主，不逐帧改变宽高。标签内容先等待挂载、滚动恢复及图层准备；持续繁忙时跳过内容动画，避免把一次阻塞变成僵硬过渡。准备耗时与动画帧间隔分别记录。键盘沿用单次布局补偿，不因插件切页额外唤起键盘。
9. 不注入跨域 iframe 内部或突破 Shadow DOM。未知结构保留原交互，不能保证任意第三方插件、DSH 版本和设备都自动达到相同帧率。

## 插件作者接口

- 标准标签页请提供 `role="tablist"`、`role="tab"`、`aria-selected`、`aria-controls` 和唯一面板 ID。
- 已处理移动布局或动画的区域可加 `data-dsh-mobile-keep-layout`，跳过自动区域识别和标签动画。
- 工作台宿主可用 `data-dsh-frame` 与直接子区域 `data-dsh-slot="center|sidebar|rightbar"` 提供稳定槽位；普通插件无需另造工作台。
- 手机约束只作用于检测到的区域，不要求任何特定壁纸或侧栏插件。

## 日志与复现

`Layout` 记录 shell / left / right / header 的存在和结构修订号；`Motion` / `Layout` 记录动画帧数、最大帧间隔及时长。诊断脚本的 `pluginTransitions` 收集最近标签页及右栏采样。

`Permission` 区分 microphone requested / opened / error 和 recording started / stopped / error；`File` 区分选择器及官方上传 requested / completed / httpError / cancelled / error。只保存阶段、状态码和错误类型，不记录文件正文、文件名、录音或转录文本。

反馈时注明插件名称/版本、步骤、减少动画设置和连接方式，并从 App 导出问题日志。发布前检查截图中的私人会话。

## 可重复验证

USB 开发版连接真机，转发该 WebView 调试端口至 9228 后运行：

```powershell
node tools/check-plugin-compat.mjs
```

脚本在真机 WebView 创建临时隔离同源框架，加载当前源码适配层，仅在框架中关闭顶层窗口保护，结束后移除；不切换真实会话或改服务器配置。合成页面模拟插件组合，文件/录音 API 合约使用桩，不上传数据或调用转录服务，不能冒充所有真实插件已验收。系统选择器和麦克风还需真机操作。

覆盖无可选插件、左右栏增删、工作台重建、缺少头部标签、陌生标签、插件自有动画、减少动画、快速切换、同名按钮、嵌套菜单、超宽弹窗和官方媒体/上传 API 合约。

2026-10-27：真机隔离框架 37 项检查通过；真实工作台的左右栏开关、遮罩关闭与官方标签切换通过。麦克风打开后立即停止、系统文件选择器打开与取消回调已回归。一次较长会话的初始标签切换采样曾出现 183–341 ms 帧间隔；调整准备时机后，本次连续采样降到 8–14 ms，录屏期间采样为 20–25 ms。这个样本不代表所有插件、首次网络加载或其他设备的性能保证；付费转写和真实会话附件上传未执行。

新版隔离 fixture 在真机通过 38 项检查，包含 HTML 根节点尚不存在时的 document-start 注入。真实 Tailscale 连接已显示欢迎页、输入框和已有会话，任务 mux 已打开。权限返回 403 的插件接口单独提示，不冒充网络故障；受限管理功能仍需在电脑操作。此结果不代表对所有第三方插件做过逐项功能验收。

## 2026-10-29 侧栏更新

手机右栏当前优先走插件原生开合，跳过快照点击拦截，关闭时整树退出命中。左栏整体与工作区独立滚动覆盖手机和平板。旧动效实验记录不代表当前手机仍运行同样快照路径，最新实测与待办见PROJECT-HANDOFF.md。
