# 悬浮对话预览开发记录

当前为本地开发改动，未发布。沿用角色、贴壁和原有连接，不新增远程服务。

展开文字框改为读取当前 WebView 已加载的对话正文，按实际宽度换行，原生滚动。首次展开默认看最新内容；停留底部时跟随新内容，翻阅历史时保留位置。顶部提示区上滑可请求原网页滚动区域加载更早内容，不后台自动遍历全部历史。单次文本最多 100000 字符；这是纯文本预览，图片、表格和代码样式不等同完整网页。

问题适配通过原网页可识别的提交/跳过面板读取原控件；选项点击、自定义回答填入、提交分别执行。每次操作校验连接档案、网页会话、问题根节点和控件仍然有效；重复操作不自动重试。问题控件放在正文前，避免被长历史挤到末尾。未知问题布局可能无法识别，不能宣称所有插件均兼容。

隐私与生命周期：只在挂件展开时读取，约每 1.5 秒合并快照，不另发历史 HTTP 请求、不访问其他 App、不将正文落盘或写日志。锁屏和回到本 App 移除挂件及回答输入框。关闭或贴壁停止读取。

2026-11-02 验证：Android 16 原网页快照读到约 1.1 万字已有内容；桌面截图确认真实多段正文已显示。隔离 iframe 的 7 项检查通过：初始历史、问题及选项识别、原控件点击、防重复、自定义输入不自动提交、历史滚动请求、切换会话拒绝旧操作。没有提交真实问题，没有产生模型请求。Kotlin 编译、debug 构建和现有单测通过。

早期默认底部跟随代码的安装组合曾被自动审批拒绝；随后圆角把手与玻璃样式测试包已经成功覆盖安装，包含该跟随代码。正文与三种材质切换已有手机截图，底部跟随完整交互尚未完成专项验收。真实新问题完整回答、分页历史实际追加、全部插件问答结构仍待验收；不能将隔离夹具等同真实业务通过。正式 App 未替换。
