# App 功能启用总览

> 装完 App 不等于功能齐全。这张表回答：**每个功能默认是开还是关、要什么权限、在哪里打开**。
>
> 数据来源：`SettingsStore.kt`、`AndroidManifest.xml` 的实际默认值（2026-11-03 核对）。改代码后请同步本表。
>
> 部署 AI 请配合 [AI 部署契约](AI-部署契约.md) 使用。

## 一、功能默认状态表

| 功能 | 默认 | 需要什么 | 在哪里开 | 不配会怎样 |
|---|---|---|---|---|
| **本地色调与调色盘** | 跟随 DSH 背景 | 无额外权限；无需联网 | 设置 → 外观 → 本地色调；浅色预设点击即保存，自定义滑动预览后点“应用配色” | 保留 DSH 自己的背景；详见[配色使用步骤](appearance-and-diagnostics.md#浅色预设与自定义调色盘) |
| **浏览 DSH 工作台** | ✅ 开（首次需引导配对） | 只需配对成功；`INTERNET` / `ACCESS_NETWORK_STATE` 安装即授 | 首次启动扫码；以后从设置 → 连接管理切换 | 核心功能，没有它别的都没意义 |
| **任务通知（通知栏进度）** | ✅ 开 | `POST_NOTIFICATIONS`（**Android 13+ 才需要授权**，低版本不弹框） | 首次启动系统弹窗 / 设置 → 通知与后台 → 通知选项 →「通知栏进度」 | 看不到任务进度，等待确认时会漏掉 |
| **审批震动** | ✅ 开 | 复用通知权限 + `VIBRATE` | 设置 → 通知与后台 → 通知选项 →「审批时震动」 | 静音环境下可能错过需要你确认的请求 |
| **后台保活（前台服务）** | ✅ 开 | `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_DATA_SYNC` | 设置 → 通知与后台 → 通知选项 →「后台保持连接」 | 切到后台后实时通道可能断，回来后要重连 |
| **网页资源复用** | ✅ 开（走 WebView/Chromium 标准缓存，上限 96 MB） | 无 | 设置 → 缓存与加载 → 网页资源（可清理） | 每次打开都重新下载插件资源（插件体量可达数 MB） |
| **诊断导出** | ✅ 开（日志记录默认开） | 无。走 FileProvider，**不需要存储权限** | 设置 → 支持与诊断 →「导出日志」 | 出问题时没有证据可提供 |
| **检查更新与公告** | ✅ 开 | 网络（访问 GitHub，发布页 <https://github.com/yiheng-zyh/DSH-Pal/releases>）；装更新需 `REQUEST_INSTALL_PACKAGES` | 设置 → 更新与公告 | 收不到新版本提示；不影响连接 |
| **扫码连接** | 一次性操作 | `CAMERA`（打开扫码即请求） | 首次启动 / 添加连接 | 只能手工粘贴配对链接 |
| **文件上传/下载** | ✅ 开 | 存储访问走系统 SAF | 使用系统文件选择器 | 无法传文件；App 只访问你选中的文件 |
| **灵动岛（媒体通道）** | ❌ **关** | 依机型/ROM（MediaStyle 音乐通道），**不需要小米焦点权限** | 设置 → 通知与后台 → 通知选项 →「灵动岛（默认关闭）」 | 小米焦点通知协议封闭，只能用媒体卡片近似显示，不是完全体灵动岛，所以默认关 |
| **悬浮助手（鲸鱼娘浮窗）** | ❌ **关** | **`SYSTEM_ALERT_WINDOW`（显示在其他应用上层）**<br>部分 ROM 另需「后台弹出界面」 | 设置 → 悬浮助手 →「显示悬浮助手」 | 浮窗根本不会出现；未授权时该页会出现「允许悬浮窗权限」按钮 |
| **对话本地缓存** | ❌ **关**（标着「实验」） | 无额外权限；正文用 AndroidKeyStore AES-256-GCM 加密落盘 | 设置 → 缓存与加载 →「对话本地缓存」开关 + 容量档位 | 断网看不到历史；**关掉开关不会删除已存内容**，要另点「清除缓存」 |
| **预测性返回** | ✅ 开（Android 14+ 才有） | 系统 Android 14 或以上 | 设置 → 外观 →「预测性返回」 | 返回手势不再预览上一屏；低版本系统此项不显示 |
| **侧栏交互增强** | ✅ **开** | 无（纯注入 JS） | 设置 → 外观 →「侧栏交互增强」 | 侧栏滚动/开合退回网页原生行为 |
| **公网通道切换插件** | 需手动装 | 插件 	ools/pal-channel-plugin（随仓库提供） | 设置里出现「公网通道」区块，或直接改 cordis.patch.yml | 只能在配置文件里手动改入口，网页里没有一键切换 |
| **通道自动选路** | ✅ 开 | 无 | 设置 → 连接管理 → 通道自动选路 | 当前通道断了不会自动换路；断线时需要你手动切 |
| **登录后自动配对** | ✅ 开 | 电脑端装 `pc-plugin/autopair.mjs`（本仓库自带） | 设置 → 连接管理 → 内置通道 → Tailscale 面板里的「登录后自动配对」 | 每次换入口都要扫一次桌面二维码 |
| **Tailscale 通道** | ❌ 关 | Android VPN 授权（`VpnService.prepare` 弹窗）+ 账号登录（电脑端安装：<https://tailscale.com/docs/install/windows>） | 设置 → 连接管理 → 内置通道 → Tailscale | 该通道不可用；不影响其他通道 |
| **WireGuard 通道** | ❌ 关，且**必须先导入配置**（未导入时连接按钮禁用） | Android VPN 授权 + 导入配置 | 设置 → 连接管理 → 内置通道 → WireGuard → 导入配置 | 该通道不可用；**没有真实服务端时即使配上也不通** |
| **IPv6 直连 / Wi-Fi 直连** | ❌ 关（需电脑侧开启） | 电脑跑 `configure-direct.mjs` | 连接管理 → 添加连接 | 该入口不存在；不影响 Relay / 国内通道 |
| **结束后立刻收起**（灵动岛） | ✅ 开 | 灵动岛已开启 | 设置 → 通知与后台 → 通知选项 →「结束后立刻收起」 | 关闭则任务结束后停留 4 秒显示结果再收起 |
| **启动时自动连接** | ✅ 开 | 已有保存的连接 | 设置 → 连接管理 →「启动时自动连接」 | 关闭后 App 启动先进选择入口页；已保存连接仍保留，不会丢 |
| **自动重连** | ✅ 开 | 无 | 设置 → 连接管理 →「自动重连」 | 断网恢复后不自动重连，要手动点；未发送内容和传输仍会保留 |
| **悬浮助手（总开关）** | ❌ 关 | `SYSTEM_ALERT_WINDOW` | 设置 → 悬浮助手 →「显示悬浮助手」 | 浮窗不出现；该页会出现「允许悬浮窗权限」按钮 |
| **悬浮助手·显示标题** | ✅ 开（开了悬浮助手才生效） | 同上 | 设置 → 悬浮助手 →「显示标题」 | 浮窗顶部不显示会话标题 |
| **悬浮助手·贴边自动收** | ✅ 开（同上） | 同上 | 设置 → 悬浮助手 →「贴边自动收」 | 拖到屏幕边缘不会自动收起，需要手动点「展开 / 收起信息」 |

## 二、必须用户本人做的权限授予（保姆级，照着点）

**AI 装不了 App、点不了系统弹窗。** 下面是每一项的**完整操作路径**，不用自己找。

---

### ① 通知权限（必做，不做就看不到任务进度）

**什么时候弹**：Android 13 及以上，**第一次打开 App 时自动弹窗**。Android 12 及以下不弹（默认就有）。

**照着做**：

1. 第一次打开 DSH Pal
2. 屏幕中间弹出「**允许 DSH Pal 发送通知吗？**」
3. 点「**允许**」

**如果当时点了"不允许"，或者没看到弹窗**：

1. 打开手机「设置」
2. 找「应用」或「应用管理」（不同品牌位置略有差异）
3. 找到「**DSH Pal**」点进去
4. 点「**通知**」
5. 把「**允许通知**」开关打开

**小米/红米（HyperOS / MIUI）额外注意**：
- 设置 → 应用设置 → 应用管理 → DSH Pal → 通知管理 → 允许通知
- 还要确认「**锁屏通知**」也开着，否则锁屏时看不到进度

**怎么确认成功了**：打开 DSH Pal → 设置 → 通知与后台 → 有「**通知能力检测**」这一项，点进去看状态。

---

### ② 相机权限（只在扫码时需要）

**什么时候弹**：第一次点「扫码连接」时自动弹窗。

**照着做**：

1. 点「扫码连接」
2. 弹出「**允许 DSH Pal 拍摄照片和录制视频吗？**」
3. 点「**使用应用时允许**」（不要选"仅这一次"）

**如果点了拒绝**：设置 → 应用 → DSH Pal → 权限 → 相机 → 选择「使用应用时允许」

> 不用扫码的话（手工粘贴配对链接），这个权限完全不需要。

---

### ③ 悬浮窗权限（只在使用悬浮鲸鱼娘时需要）

**这是最容易被 ROM 拦住的一项。** 有两层。

**第一层：App 内直接跳转（最省事）**

1. 打开 DSH Pal → 设置
2. 点「**悬浮助手**」
3. 页面里会显示提示：「还需允许「显示在其他应用上层」权限…」
4. 点下面的「**允许悬浮窗权限**」按钮
5. 系统跳到权限页 → 找到「**DSH Pal**」→ 打开「**允许显示在其他应用上层**」/「**显示悬浮窗**」
6. 按返回键回 App，提示会变成「**悬浮窗权限已允许**」

> 如果点了按钮提示「系统未提供权限入口，请到应用信息中允许悬浮窗」，就手动走：设置 → 应用 → DSH Pal → 找「显示在其他应用上层」。

**第二层：部分小米/红米还需要「后台弹出界面」**

1. 设置 → 应用设置 → 应用管理
2. 找到「**DSH Pal**」点进去
3. 找「**后台弹出界面**」（有的系统叫「后台弹出界面权限」或「显示悬浮窗」）
4. 打开它

**第三层：回到 App 打开开关**

1. DSH Pal → 设置 → 悬浮助手
2. 把「**显示悬浮助手**」开关打开
3. 回到主界面，应该能看到鲸鱼娘浮窗

**如果还是不出现**：检查「后台保持连接」是否开着（设置 → 通知与后台 → 通知选项）。关掉后台连接时悬浮助手也会停，App 里明确写了这点。

---

### ④ 安装未知应用（只在 App 内更新时需要）

1. App 里点「检查更新」→ 下载完成后提示安装
2. 系统弹「**为了安全，你的手机不允许安装未知应用**」
3. 点「**设置**」→ 打开「**允许来自此来源**」
4. 返回 → 点「安装」

---

### ⑤ VPN 授权（只用 Tailscale / WireGuard 时需要）

**什么时候弹**：第一次点「连接并打开 DSH」时。

1. 弹出「**DSH Pal 想要设置一个 VPN 连接…**」
2. 点「**确定**」/「**允许**」

> **注意**：Android 同一时间只能有一个 VPN。如果手机上有别的 VPN 在跑，需要先关掉它。

---

### ⑥ 电池优化（可选，但国产 ROM 强烈建议）

**App 没有自动申请入口**（源码里没有任何 `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` 实现），**必须手动设**。

**不设会怎样**：系统会在后台杀掉 DSH Pal → 任务通知停、实时通道断 → 表现为「App 好像死了」。这不是 App 的 bug。

> ⚠️ **下面各品牌的路径是按常见位置写的，厂商在不同版本里会改菜单名。**
> 如果找不到，用**通用方法**（一定有效）：
> 打开手机「设置」→ 顶部**搜索框**输入「**电池优化**」或「**锁屏清理**」或应用名「**DSH Pal**」→ 直接从搜索结果进去。
> 搜索是各家 ROM 都保留的功能，比记菜单路径可靠。

**小米/红米（HyperOS / MIUI）** —— 已在真机确认存在对应系统组件：

1. 设置 → 应用设置 → 应用管理 → 找「**DSH Pal**」
2. 点「**省电策略**」→ 选「**无限制**」
3. 返回上一级 → 点「**自启动**」→ 打开

**其他品牌**：在自己的系统设置里找同名或近似项，关键词是这三个 ——
「**电池优化 / 省电策略**」设为不限制、「**自启动 / 允许后台活动**」打开、「**后台弹出界面**」打开。

**原生 Android**：设置 → 电池 → 电池优化 → 找到 DSH Pal → 选「不优化」

> **判断标准**：切到后台 10 分钟再回来，App 不需要重新加载、连接还在 = 设对了。

## 三、按场景推荐配置

### 场景 A：只想要「手机能看能聊」

```
必开：通知权限 + 后台保活（这两项默认已开，只需给权限）
不用管：灵动岛、悬浮助手、VPN、对话缓存（全部默认关，不影响基本使用）
```

### 场景 B：想在通知栏跟进度

```
场景 A + 通知权限已授予
可选：设置 → 通知与后台 → 通知选项 →「灵动岛（默认关闭）」（小米/红米机型，接受"媒体卡片"外观再开）
```

### 场景 C：想要悬浮鲸鱼娘

```
场景 A + 悬浮窗权限 + 部分 ROM 的「后台弹出界面」
设置 → 悬浮助手 →「显示悬浮助手」开启
未授权时该页会出现「允许悬浮窗权限」按钮，点了直达系统设置
```

### 场景 D：经常断网想查历史

```
场景 A + 设置 → 缓存与加载 →「对话本地缓存」开启
注意：① 这是实验功能，只对开启后新产生的消息可靠；历史会话走 DOM 兜底、角色记为「对话」
     ② 关掉开关不会删除已存内容，要另点「清除缓存」
     ③ 正文加密存在 App 私有目录，不随云备份/换机迁移
     ④ 想确认它有没有在工作：同一页有「同步状态」，显示
        正在同步 / 未在同步、上次同步时间与会话名、待写入条数、本次已同步会话数；
        另有「立即同步」按钮立刻落盘，不必等 45 秒自动周期
```

## 四、常见「看着像 bug 其实是没配」的现象

| 现象 | 真实原因 | 怎么办 |
|---|---|---|
| 切到后台一会儿就断，回来要重连 | 系统杀了后台进程（ROM 省电策略） | 自己去系统设置把 DSH Pal 设为「不限制」。App 没有自动申请电池白名单的入口 |
| 通知栏没有任务进度 | 通知权限没给（Android 13+） | 系统设置里授权；设置页有「通知能力检测」可看实际状态 |
| 悬浮助手怎么都不出现 | 悬浮窗权限没给，或 ROM 拦了「后台弹出界面」 | 设置 → 悬浮助手 里有「允许悬浮窗权限」按钮；ROM 层那项要自己找 |
| 灵动岛没有真正的岛形状 | **设计如此**：小米焦点通知协议封闭，只能用 MediaStyle 近似 | 这是已知死路，不是 bug |
| 页面加载很慢 | 插件首屏资源体量大（三份 bundle 的 gzip 合计约 8.7 MB） | 靠 WebView 标准缓存，第二次会快；App 自建的资源拦截只在 USB 开发构建下生效 |
| 断网后看不到历史 | 对话缓存默认关 | 按场景 D 开启 |
| 提示「未配对」但 VPN 明明连上了 | VPN 解决网络可达，配对是另一层 | 重新扫码配对，见 connections.md |
| 连着 VPN 试几次之后，连电脑都发现不了了 | Tailscale 隧道可能只通了半边：控制面显示已连接，但数据回不来（两端落在不同的中继节点时常见） | 看内置通道页是否有「这条 VPN 通道在当前网络下不通」的说明。同一 Wi-Fi 下改用 Wi-Fi 直连；外网改用公网通道 |
| 正用着某个通道，突然被自动切到另一条 | 通道自动选路的「保命切换」在连续两次探测不通时触发；**会先弹提示并倒计时 15 秒**，不会静默换掉 | 弹提示时点「继续用当前通道」即可保留，30 分钟内不再问。想彻底关掉：设置 → 连接管理 → 通道自动选路 |
| 登录 Tailscale 之后还是要扫二维码配对 | 「登录后自动配对」开关关了，或电脑端没装 `pc-plugin/autopair.mjs`，或这台手机不在电脑的 tailnet 里 | 内置通道页确认开关是开的；电脑端确认 `cordis.patch.yml` 里有 `dsh-mobile-autopair` 条目并重启过 DSH。仍不行就用手动配对（可选）扫一次 |
| 灵动岛任务结束后停很久不收 | 「结束后立刻收起」关了（默认开） | 设置 → 通知与后台 → 通知选项 →「结束后立刻收起」打开 |
| 每次开 App 都要先点一下选入口 | 「启动时自动连接」关了（默认开） | 设置 → 连接管理 →「启动时自动连接」打开。注意：这会跳过选择页，直接连上次那条 |
| 断网恢复后页面还是断的，要手动点 | 「自动重连」关了（默认开） | 设置 → 连接管理 →「自动重连」打开。它保留未发送内容和传输，不会丢草稿 |
| 悬浮助手不显示会话标题 / 拖到边缘不自动收 | 「显示标题」/「贴边自动收」关了（默认都开） | 设置 → 悬浮助手 里对应开关打开；找不到时先确认「显示悬浮助手」本身是开的 |
| 更新提示里有「开发预览版本」 | alpha 构建（版本名含 `-`）默认接收预览 | 设置 → 更新与公告 里关掉即可；正式版默认不接收 |
| **重开 App 时一直转圈/白屏** | 「当前连接」指向一条**已经失效的地址**（以前 VPN 的网关、换过 IP 的局域网入口） | **现在会自动处理**：启动时先探一次，连不上就直接把你带到「设备与连接」页并说明原因，不用再手动禁用那条地址。见 4-1 |

### 4-1 启动时那条连接连不上，现在会怎样

以前：App 只看「有没有存过地址」，就照旧加载它。地址早就失效时，你会看到白屏，
要等约 29 秒（两次巡检 + 15 秒倒计时）才可能自动换一条。

现在（2026-11-05 起）：

1. 启动时先探一次当前连接，**最多 4 秒**出结果
2. **连不上** → 不加载那条地址，直接进「设置 → 设备与连接」，顶部写明
   「上次的连接现在连不上：`<地址>`。`<原因>`」
3. 两个动作：
   - **重试这条** —— 万一只是刚才网络抖了一下
   - **先不用这条** —— 撤掉提示，按普通流程走
4. 想换一条？**不用额外操作** —— 你现在就在「设备与连接」页，下面的列表直接点就行
5. **那条坏连接不会被删**，随时能切回来

不会被打断的情况（探测会自动跳过，行为和以前完全一样）：

| 情况 | 行为 |
|---|---|
| 连接正常 | 不多等，直接加载 |
| 「启动时自动连接」关着 | 直接进选择页，不探测 |
| USB 数据线通道 | 不探测（它走 adb，普通网络探测会误判） |
| 正在扫码配对 | 不探测（配对链接有有效期，不能当失效） |
| 返回 401/403 | 算「通」—— 那是没配对，不是连不上 |

## 五、如何确认自己配齐了

**电脑端**：跑 `node tools/deploy-status.mjs`，看 `todo` 是否清空。

**手机端**（只能人工确认，没有自动检测）：

- [ ] 打开 App 能看到工作区和已有会话
- [ ] 顶部连接类型显示正确（Relay / Cloudflare / 自建固定域名 / Wi-Fi 直连 等）
- [ ] 发一条消息能收到回复（这是最直接的业务验证）
- [ ] 切到后台再回来，连接还在
- [ ] 想用的功能（通知/悬浮/媒体岛）确实出现了

四项都过，才算这台手机配好了。
