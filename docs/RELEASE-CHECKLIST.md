# DSH Pal 首次公开检查表

此文件是发布流程，不是“已经可以发布稳定版”的证明。

## 源码公开之前

- [ ] 从准备好的公开源码快照建立独立仓库；不直接推含私人运维记录的本地原仓库。
- [ ] 检查当前树和提交历史中的端点、账号、Cookie、token、私钥、签名、本机路径、序列号与私有截图。
- [ ] README、连接文档、总交接的状态一致，包含仍未解决的故障；不写全部通道已通过。
- [ ] `LICENSE`、第三方文本、角色来源与署名完整。代码Apache-2.0与角色CC BY-NC-SA分开说明。
- [ ] 从ASCII路径干净导入；准备原生Tailscale库、JDK21/SDK36，完成构建与测试。
- [ ] CI配置已包含Windows下准备原生库、Node脚本检查和Kotlin单测；首次GitHub运行仍需实际观察。
- [ ] 仓库地址确定后再补README/关于页/视频简介，不能使用他人项目地址冒充。

## 体验包或Release之前

- [ ] 先处理平板熄屏启动的前台服务超时，复测冷/热启动与返回前台。
- [ ] 正式包公网进入、任务实时通道和至少一项无副作用业务响应验收；USB结果不替代。
- [ ] 原入口→目标→原入口、失败和取消路径验证，不丢登录/草稿，VPN按需停止。
- [ ] 手机/平板左右栏、嵌套滚动、窗口变化、通知开关与文件实际上传分别检查。
- [ ] WG、未覆盖插件、平板通知详情等限制如实写入Release。
- [ ] 确定版本名与递增versionCode；当前基线仍versionName1.0.0/versionCode1，不把旧编号当新发布策略。
- [ ] 使用维护者自己的稳定签名并离线保管，不上传keystore或密码；debug回退签名不可称正式签名。
- [ ] 产物校验签名和SHA-256，正常release非debuggable、未开启USB/CDP；真机只覆盖安装。
- [ ] 首次不确定兼容性时使用开发预览/Pre-release，检查项未过不发布为稳定版。

## 对外演示之前

- [ ] USB开发演示和通知UI预览有角标；无虚构公网测速或永久后台承诺。
- [ ] 素材授权/角色署名、AI辅助插画说明随片尾/简介保留。
- [ ] 全片/封面/简介不含私人会话、配对码、账号、端点、设备标识。
- [ ] 公开地址和下载实际存在；仓库尚未公开时使用“准备开源”的开发记录文案。
