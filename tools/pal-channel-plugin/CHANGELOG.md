# dsh-pal-channel 更新记录

> 面板里的「更新公告」就来自这个文件：`lib/update.js` 通过 jsDelivr 读仓库里的
> 这份 CHANGELOG，取**最新版本号对应的段落**展示。发版时在这里加一段，用户就能看到改了什么。

## 未发布

### 新增

- **连接通道总览**：在 DSH 设置里一次看清所有通道——公网隧道（国内 frp / Cloudflare）、
  IPv6 直连、Wi-Fi 直连各自处于什么状态（当前使用 / 已开启 / 未配置 / 已开启但未监听）。
  状态来自网关实测的 `state.json`（含 20 秒新鲜度校验），不是猜的。
- **直连入口开关**：IPv6 直连与 Wi-Fi 直连可以在面板里直接开关，写的是 remote-access 配置，
  网关 5 秒内热生效，不需要重启 DSH。
- **插件更新检查**：显示当前版本、检查是否有新版、展示更新公告，并提供一键更新入口。

### 修复

- 版本比较把预发布版本（`0.1.0-alpha.7`）判成与正式版（`0.1.0`）相同的问题。
- 通道体检的 IPv6 地址判据与网关不同源，会把 Teredo / WSL 等虚拟接口算成可用地址。

## 0.1.0 - 2026-11-05

### 新增

- 在 DSH 界面里一键切换公网入口：国内 frp ⇄ Cloudflare 隧道。
- 切换前预检目标入口，验不过就拒绝切换，避免生成连不上的二维码。
- 切换时同步启停另一套隧道客户端，避免两条隧道同时占着出口。
- 写接口只允许本机桌面调用，远程配对设备一律拒绝。
