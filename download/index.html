装之前先看这个

  1. 这是手机端。电脑上要先装好 DSH，手机才有东西可连：电脑端下载。
  2. 点开 APK 安装；系统提示「禁止安装未知来源应用」时允许一次即可。
  3. 装完打开，按引导扫码配对或填电脑地址。
  4. 覆盖安装不会丢数据，更新时直接装新版，不要卸载。

确认文件没被改过（建议做）

官方安装包的 SHA-256：

—
Windows 上怎么核对（30 秒，不用装软件）
  1. 把 APK 和 SHA256SUMS.txt 放在同一个文件夹。
  2. 在该文件夹的地址栏输入 cmd 回车。
  3. 粘贴并回车：certutil -hashfile DSH-Pal.apk SHA256
  4. 输出的一串和上面的完全一样，说明文件没被改过。

手机上不方便时：用 MT 管理器等文件工具长按文件 → 属性 / 校验值 → SHA256，同样对比。

装不上 / 报错怎么办
  • 提示「与已安装版本冲突」「签名不符」：这不是官方签名包，别装，回来重新下载。
  • 提示「解析包错误」：下载不完整，重下（建议 WiFi）。
  • 装完白屏或连不上：多半是电脑端 DSH 没开或地址不对，先看 App 里「连接帮助」。

任何「修改版」「破解版」「内置加速版」都不是官方包，不要安装。只认准本页和 GitHub Releases 两个来源。
