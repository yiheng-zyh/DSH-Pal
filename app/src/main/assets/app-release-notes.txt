DSH Pal 0.1.3

• 新增「网页兼容与排查」，专治插件惹的祸：
  设置 → 网页兼容与排查。可以为每个连接单独做两件事：
  ① 选「使用 DSH 原始网页」，暂停 Pal 对网页布局、外观和交互的调整（用于判断
     是不是 Pal 的增强导致的）；
  ② 单独暂停某个插件（例如壁纸引擎）。列表会把「本页加载失败的插件批次」
     排在前面并标注，方便你按可疑顺序逐个试。
  暂停只作用于这台手机的当前连接，改动会提示你先保存未发送的内容再重载。
  点「取消所有暂停」+「应用兼容设置」即可完全恢复。壁纸主插件被暂停时，
  它的动效、字体、玻璃等子模块会一起暂停；但如果有别的插件依赖它，
  那部分会自动保留并在列表里说明。

• 新增「诊断当前页面」：一键检查输入区是不是被别的网页元素盖住了
  （结果显示「可命中 / 有遮罩 / 当前不可见」），排查「打字框点不动」时有用。

• 悬浮助手能看对话了：展开后直接显示当前会话的对话预览（区分「我」和「助手」），
  自动跟随最新消息；右下角可以拖动调大小。

• 输入框「+」不再顶掉键盘位置：点加号弹命令菜单时，只收起安卓键盘、保留输入焦点，
  菜单过高时内部滚动，不再整页被撑开。

• 设置页改成分组搜索：连接 / 界面与通知 / 网页与数据分组，带关键词搜索，
  入口多了也能直接搜到。

• 缓存管理新增网页缓存实测：显示当前页面测到的静态资源项数、缓存复用项数
  和体积，不再只是一个「清理」按钮。

• 连接通道名称调整：原来叫「其他 HTTPS / frp」的改叫「frp / HTTPS 反向代理」，
  用 SAKURA FRP 的地址会自动显示成「SAKURA FRP」，不再只显示技术分类名。

• 另外修了几处：右侧栏关闭时先让 DSH 退出全屏布局（避免关掉后对话区用不了）；
  移动端侧栏入口在隐藏状态下不再误显示。

已知限制：
• 平板熄屏启动的前台服务超时仍在排查，本版未修。
• 「暂停插件」依赖页面提供插件清单；某些插件组合下列表可能为空，
  此时仍可用「使用 DSH 原始网页」排查。
• 本版在小米手机（Android 16）验证；其他 ROM 与平板未覆盖。
• 覆盖安装保留现有数据与连接配置（不卸载、不清数据）。
